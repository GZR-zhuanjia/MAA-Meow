# 定时配置任务链

在定时策略的任务配置区域选择「任务链」，添加至少两个不同配置，使用「上移 / 下移」调整顺序。固定时间和间隔周期均可使用。旧策略默认保持「单配置」。已删除的配置会显示失效提示，保存前需要移除或替换。

每轮使用该配置自己的任务。需要切号时，请在每个配置中启用「启动游戏」并填写账号；账号切换沿用现有启动游戏任务，只支持其已有客户端（Official、Bilibili、txwy、YoStarKR）。任务链本身不额外强停或重启游戏，也不替代客户端的登录验证。

只有上一配置全部任务正常完成后才推进；任务错误、启动失败、失效配置、空任务、手动停止、掉线中止或运行时长上限都会结束整链。只包含旁路任务的配置也会等待其结果。触发日志显示当前配置和序号。

倒计时与唤醒只在整链开始执行一次，策略与全局关闭游戏、自动熄屏、屏保释放及退出应用在整链结束时收尾。运行中可使用原任务停止按钮终止整链；请先停止任务链再手动启动其他任务。强制启动的新请求会取消并接管旧请求。
